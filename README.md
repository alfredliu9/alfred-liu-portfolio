# alfredliu.ca

Alfred's maze worksheet: a single static page (`index.html`). Walk Alfred through the maze and pick up each item to read about it.

- Content lives in the `CONTENT` array near the top of the `<script>` in `index.html`.
- `alfred-liu-resume.pdf` is served at `/alfred-liu-resume.pdf`.
- `vercel.json` sets the framework to none, so Vercel serves the files as-is (no build step).

The previous Next.js portfolio is kept on the branch `backup/nextjs-portfolio-2026-11-05` and the tag `old-portfolio-2026-11-05`.
